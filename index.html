If the mic won't work

Use Safari on iPad, or Chrome or Edge on a computer. Allow the microphone when it asks. To stop Safari asking every time: tap aA in the address bar → Website Settings → Microphone → Allow. Dictation must be on: Settings → General → Keyboard → Enable Dictation.
